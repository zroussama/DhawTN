3. STEG Facebook Post Automation

The game changer: acting as the single source of truth by autonomously scraping, parsing, and mapping official STEG announcements using NLP and PostGIS fuzzy matching.

📡

Scraping the Source

A Python scraper acts as an autonomous agent, periodically checking the official STEG Facebook page for new posts containing keywords like "coupure" or "انقطاع".

GET /facebook.com/STEG.Tunisie/posts
🧠

Natural Language Processing

The raw Arabic text is processed to extract structured JSON data. It identifies the date, start time, end time, and a list of affected string locations.

{ "date": "2026-07-28", "time_start": "08:00", "time_end": "14:00", "areas": ["قفصة الشمالية", "القصرين"] }
🔀

PostGIS Spatial Matching

Transliteration algorithms convert Arabic strings to match internal database geometries. The system executes fuzzy matching against the steg_affected_areas table.

INSERT INTO steg_affected_areas ( announcement_id, area_name, delegation_id ) VALUES ( 'uuid', 'قفصة الشمالية', (SELECT id FROM tunisia_delegations WHERE name ILIKE '%Gafsa Nord%' LIMIT 1) );
🗺️

Time-Aware Rendering

The frontend queries the Supabase database. If the current time falls between time_start and time_end, the associated PostGIS geometry is rendered as a critical red polygon on the map.
